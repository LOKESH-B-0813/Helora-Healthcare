## 🌟 Featured Projects

### 🏥 [FlowPulse AI](https://github.com/Muthudeenathayalan/flowpulse)
**Predictive Hospital Flow Intelligence & Counterfactual Operations Platform**
- Predicts patient waiting times and total door-to-door visit completion across multi-stage care pathways.
- Models cross-department ripple effects when disruptions occur (e.g. lab analyzer outages propagating to bed boarding).
- Counterfactual scenario simulator allowing hospital operations managers to test and authorize interventions with human-in-the-loop governance.
- Synchronized patient mobile app with adaptive arrival window targeting and real-time care milestone tracking.
- **Tech Stack**: Next.js 16, React 19, TypeScript, React Native, Expo, Supabase (Realtime PostgreSQL), Tailwind CSS v4, React Flow, Recharts.

### 🐔 [FlockSense](https://github.com/Muthudeenathayalan/flocksense)
**Smart Poultry & Agricultural Intelligence System**
- IoT and vision-enabled monitoring platform for poultry farm environmental metrics, bird distribution, and anomaly detection.
- Real-time telemetry dashboards and proactive alerts to improve flock welfare and operational yield.
- **Tech Stack**: Python, Computer Vision, React, Node.js, IoT Telemetry.

### 📈 [Predicto](https://github.com/Muthudeenathayalan/predicto)
**Predictive Time-Series & Financial Analytics Platform**
